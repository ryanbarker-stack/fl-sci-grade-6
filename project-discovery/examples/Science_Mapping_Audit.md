## Limits and corrections

A design hobby does not automatically imply anatomy; baking alone does not establish microbiology; game codes do not by themselves establish genetics. Those links need a selected phenomenon or explicit follow-up. The first implementation reused one option key for two comparison choices; the uniqueness test and browser inspection caught this, and each option now has its own key. Resource access and consultant skill never create domain tags.
